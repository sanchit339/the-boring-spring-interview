### ⚡ TL;DR — Why This Exists (For Doom-Scrollers)

Most interview prep guides are **boring for the wrong reasons**: 
- Page-long paragraphs explaining what an interface is.
- Generic answers generated by ChatGPT that sound smart but get you rejected in 2 minutes.

**This handbook is boring for the RIGHT reasons:**
- 🎯 **Answer in 3 Sentences** — Direct. What it is, key rule, what breaks if you don't.
- 💡 **Real Analogies** — Mental models that map 1:1 to production concepts.
- 🚨 **`BAD` vs `GOOD` Code** — Real production classes (`OrderService`, `PaymentGateway`), not `Foo` and `Bar`.
- 💣 **Interview Traps Labeled** — `// NPE here`, `// Memory leak`, `// Race condition`.
- 🙋‍♂️ **"Ask Next" Follow-ups** — The exact follow-up questions real interviewers throw at 2+ YoE devs.

---

### 🧠 The 2-Rule Format (How Every Answer Is Structured)

```
┌───────────────────────────────────────────────────────────────────────────┐
│ 1. EXPECTED ANSWER  (3-5 Sentences Max)                                   │
│    • What it is                                                           │
│    • Key rule / key difference                                            │
│    • What breaks if you don't use it                                      │
├───────────────────────────────────────────────────────────────────────────┤
│ 2. PRACTICAL EXPLANATION                                                  │
│    • Real-world Analogy                                                   │
│    • BAD Code vs GOOD Code (with inline traps)                            │
│    • Spring Boot / Production context                                     │
└───────────────────────────────────────────────────────────────────────────┘
```

### 💻 Quick Start

Clone, install, and run locally in **Linear-style dark mode**:

```bash
# Clone the repository
git clone https://github.com/sanchit339/the-boring-spring-interview.git

# Navigate to project
cd the-boring-spring-interview

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open `http://localhost:4321` in your browser. `⌘K` search supported out of the box.
